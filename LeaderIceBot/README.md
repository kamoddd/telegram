# Telegram-бот расписания льда

Бот:
- отправляет 2 картинки расписания по кнопке `Расписание`;
- проверяет сайт раз в час;
- если картинки изменились, рассылает обновление всем подписанным пользователям.

## Стек
- Python 3.10+
- `python-telegram-bot` (long polling)
- `requests` + `BeautifulSoup`
- SQLite (локально)

## 1) Создать бота в Telegram
1. Открой `@BotFather`.
2. Выполни `/newbot`.
3. Скопируй токен.

## 2) Настройка проекта
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Заполни `.env`:
- `BOT_TOKEN` - токен от BotFather
- `TARGET_URL` - сайт с расписанием
- `CHECK_INTERVAL_MINUTES` - интервал проверки (по умолчанию `60`)
- `DB_PATH` - путь к SQLite базе

## 3) Запуск
```bash
source .venv/bin/activate
python bot.py
```

## 4) Как пользоваться
- Напиши боту `/start` - чат подпишется на обновления.
- Нажми кнопку `Расписание` - бот отправит 2 актуальные картинки.
- Команда `/stop` отключает уведомления.

## Как это работает
1. Бот парсит страницу и находит 2 картинки расписания.
2. Скачивает картинки и считает `sha256`.
3. Сравнивает хэши с прошлым состоянием в SQLite.
4. При изменениях отправляет обновление подписчикам.

## Примечание по хостингу дома
Проект использует **long polling**, поэтому входящий порт открывать не нужно.
Достаточно, чтобы машина имела исходящий доступ в интернет.
